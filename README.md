# GroceryStore Admin Panel

A modern, professional PHP-based admin panel for managing products and users in an online grocery store.

## Features
- Admin login (secure)
- Product management (add, edit, delete, image upload)
- User management (view registered users)
- Modern dashboard with stats (total users, total products)
- Beautiful gradient sidebar and responsive design

## Setup

1. Clone/download this repo to your XAMPP `htdocs` folder.
2. Import the provided SQL tables (`products`, `users`) into your MySQL database.
3. Update database credentials in `admin/config.php` if needed.
4. Make sure the `uploads/` folder exists and is writable.
5. Start XAMPP and visit `http://localhost/your-folder/admin/login.php`
